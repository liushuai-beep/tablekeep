TableKeep 0.3 · macOS 菜单栏应用预览版

先看效果
打开同目录交付的 TableKeep.app（Apple Silicon Mac）。
应用启动后显示空面板；点击顶部菜单栏表格图标可展开或收起。
点击“试用示例”可查看演示；右键菜单栏图标可退出。

建议这样试
1. 看默认示例的多级表头、跨行单元格和嵌入图片。
2. 点击“简化中转 · 模拟”，查看哪些结构被改变；点击问题会定位到对应内容。
3. 点击“恢复保真结果”。
4. 直接在中间结果里修改一个数字，观察损失检查更新；可再次恢复。
5. 切换“图片待补入”，从本机补入一张 PNG/JPEG/GIF。
6. 复制自己的表格后点击“读取剪贴板”，或导入 HTML / Markdown / 文本文件。
7. 点击“导出 DOCX”，用自己的 Word/WPS 查看实际结果。

已实现
- 本机解析 HTML 与基础 Markdown，保留支持的行列合并关系。
- 保留单元格文字、换行、加粗/斜体/上下标/链接和嵌入图片。
- 比较识别到的内容与转换结果，检查结构、文字、数字序列、代码、图片和公式原文。
- 原生剪贴板读写、文档导入、图片补入、DOCX/HTML/JSON 检查报告导出。
- 不自动下载外部图片；转换过程不上传内容，不保存粘贴历史。

边界
- 这是功能原型，检查只覆盖已识别的内容与支持的样式，不覆盖全部 HTML/CSS。
- 公式目前保留 LaTeX/MathML 原文，没有转为 Word 原生可编辑公式。
- 未嵌入的外部图片在 DOCX 中显示占位文字；请先从本机补入。
- 表格最多 200 行、40 列；文本最多 18 万字符；单张补入图片最多 10 MB。
- 预览不能代替 Word/WPS 的实际排版验收。
- “简化中转”是故意制造降级的内部演示，不是 PasteMD 或其他工具的实测。

开发运行
1. 使用 Node.js 22.12 或更高版本。
2. 在这个源码目录运行 npm ci。
3. 运行 npm start。
4. package-lock.json 固定了本次依赖；Electron 开发包可能在首次启动时下载运行时。
5. npm run package:mac 生成 Apple Silicon Mac 本机临时签名应用；未做开发者证书签名与公证。

源码结构
main.cjs / preload.cjs：原生窗口、受限剪贴板与文件桥接。
engine.js：独立的内容模型、HTML/基础 Markdown 解析、转换和损失检查。
docx.js：OOXML 与 ZIP 写出，支持 gridSpan/vMerge 和嵌入图片。
app.js / index.html / styles.css：工作台交互与界面。
samples.js：标明为演示数据的三个例子。
