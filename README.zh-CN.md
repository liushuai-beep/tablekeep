# TableKeep

**把合并表格完整地带过去，先看清转换中发生了什么。**

常驻 macOS 顶部菜单栏的表格转换小工具。点击图标，粘贴表格，检查合并关系和内容变化，再复制富文本或导出 DOCX。复杂问题可以展开详细工作台，两种视图共享同一份内容。

[下载 Apple Silicon Mac 版本](https://github.com/liushuai-beep/tablekeep/releases/latest) · [English](README.md)

![菜单栏小面板](docs/menubar.png)

## 已实现

- 菜单栏图标、紧凑只读预览、Esc / 点击外部收起；可固定面板。成功复制后默认收起，固定时保持展开；关闭后继续常驻，不显示 Dock 图标。
- 显式读取剪贴板，或使用全局快捷键 `⌘⇧V`，在更多菜单可改成 `⌘⌥V` 或关闭。快捷键被占用时会提示，仍可使用按钮；不会自动扫描剪贴板。
- 保留支持的跨行、跨列、多级表头、嵌套表格、空单元格、前导零、换行与嵌入图片。
- 对比单元格位置、跨度、文字、数字序列、强调、链接、代码、图片和公式原文；点击问题可定位。
- 从输入原文恢复结果、从本机补入图片、复制富文本，导出 DOCX / HTML / JSON 检查报告。
- 本机处理，无账号、无粘贴历史、无遥测，不自动下载外部图片。

## 怎么试

1. 从 [Releases](https://github.com/liushuai-beep/tablekeep/releases) 下载 arm64 ZIP，解压后把 `TableKeep.app` 放入 Applications 并打开。
2. 点击顶部表格图标，在原应用中复制内容，再点击「读取剪贴板」。
3. 初次也可以点「试用示例」，观察合并表格和内嵌图片。
4. 点击检查摘要或「展开工作台」，查看输入、结果和问题定位。试改一个金额可触发真实变化检查。
5. 复制富文本或导出 DOCX，用自己的 Word/WPS 打开确认最终排版。
6. 右键点击菜单栏图标可退出。

预览包只做了本机临时签名，**没有 Apple 开发者证书签名与公证**，首次启动可能被系统拦截。请先审阅源码；确认信任后通过系统「隐私与安全性」中的提示打开，或自行构建。当前仅打包和验证了 Apple Silicon Mac。

## 当前边界

这是可实际操作的早期原型。检查覆盖已识别内容和支持的样式，不等于任意格式完全保真。

- 输入支持 HTML 富文本、基础 Markdown、制表符分隔的 TSV 表格、文本及相应文件；暂不直接导入 DOCX/XLSX/PDF，也不做 OCR。
- 公式保留原文并提示限制，暂不生成 Word 原生可编辑公式。
- 外部图片需从本机补入；SVG 会明确提示不支持。
- 样式支持加粗、斜体、下划线、上下标、代码和链接，不覆盖任意 CSS、字体和页面布局。
- 表格上限 200 行、40 列；非图片输入上限 18 万字符，含嵌入图片的总内容上限 25 MB；本机补入图片上限 10 MB。
- 「简化中转 · 模拟」是内部损失演示，**不是 PasteMD 或其他工具实测**。
- 检查比较输入与应用内结果；Word/WPS 或目标软件的最终显示仍需实测。检测到损失后会暂停复制/导出，直到恢复完整内容。

## 本次实测

见 [实验记录](EXPERIMENTS.zh-CN.md)：记录旧版发现的问题和修复结果、25 项核心回归、11 项隔离界面检查、13 项原生窗口检查，以及 Pages 实际打开文件后的观察。Word/WPS 最终渲染仍未验证。偏好文件只存固定面板、复制后收起和快捷键设置，不保存文档内容。

## 菜单栏操作

- 顶部图标单击展开或收起，右键打开原生操作菜单。
- 图钉用于保持面板展开；更多菜单提供设置、导入导出和退出。
- `⌘V` 粘贴新内容，`⌘↵` 复制富文本，`⌘O` 导入，`⌘S` 导出 DOCX，`⌘D` 切换工作台，`⌘W` 收起。
- 小面板只预览；在工作台编辑，检查更新前暂停复制/导出。

## 本机开发

需要 macOS、Node.js 22.12+。

```sh
npm ci
npm start
npm test
npm run test:ui
npm run test:native
npm run package:mac
```

首次运行 Electron 可能需要下载运行时。打包结果位于 `../TableKeep-build/`。`npm test` 在 Electron 中运行 25 项核心回归检查；CI 同时运行检查和打包。实现结构见 [英文 README](README.md#how-it-fits-together)。

欢迎贡献脱敏表格样例、Word/WPS 兼容性验证、原生公式支持、英文界面和其他桌面平台支持。详见 [贡献说明](CONTRIBUTING.md)。
